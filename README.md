# Loan Prediction Based on Customer Behaviour

## 📌 Project Overview

This project focuses on analyzing customer behaviour and building a machine learning model to predict loan-related outcomes.

The project includes data analysis, data preprocessing, exploratory data analysis, feature engineering, model building, and model evaluation.

## 🎯 Objective

The main objectives of this project are:

- Analyze customer behaviour and loan-related data
- Understand important factors affecting loan prediction
- Clean and preprocess the dataset
- Perform exploratory data analysis
- Build a machine learning prediction model
- Evaluate the model's performance

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab
- Jupyter Notebook
